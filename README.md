# Travel-Booker-Prototype
This project was developed as part of an academic Agile Project Management module, focusing on designing a web-based travel booking platform for both B2C and B2B users.

##  Project Overview
The objective was to propose and develop a prototype solution for a travel booking system using Agile methodologies. The project followed an iterative approach, incorporating continuous feedback and incremental improvements.

##  My Role
- Scrum Master
- Quality Assurance Lead

I facilitated Agile ceremonies, coordinated team activities, and ensured quality throughout the development lifecycle.

##  Key Features
- User Story Mapping and backlog creation
- MVP (Minimum Viable Product) prioritisation
- Interactive high-fidelity prototype
- Support for both B2C and B2B booking flows
- Iterative development with continuous feedback

- Task tracking and progress monitoring
